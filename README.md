# arisa

환경 변수:
- `ARISA_BIND`: bind 주소, 기본값 `0.0.0.0:3000`
- `ARISA_UID`: Android user id
- `ARISA_CALLING_PKG`: Android 호출 package, 기본값 `com.android.shell`
- `ARISA_DB_PULL_DELAY`: DB 폴링 딜레이(ms), 기본값 `100`
